# Mini Mundo de Bloques

Web estática sencilla inspirada en juegos de construcción de bloques. Incluye editor de paisaje y guardado local.

## Publicación en GitHub Pages
1. Sube `index.html` a la raíz de un repositorio público.
2. Ve a **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Abre la URL que GitHub Pages genere.

No requiere instalaciones, claves API ni servidor. Proyecto no oficial, sin afiliación a Minecraft/Mojang.
